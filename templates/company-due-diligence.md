# 可复制｜公司与岗位尽调表

| 项目 | 需要核实什么 | 核实方式 | 证据/未知 |
|---|---|---|---|
| 招聘公司主体 | 完整法定名称、统一社会信用代码 | 国家企业信用信息公示系统 | |
| 劳动合同签署主体 | 是总公司/子公司/外包/第三方？ | 招聘方书面确认 | |
| 岗位真实性 | 是否仍开放、编号与招聘联系人 | 官网或已确认官方招聘渠道 | |
| 职责权限 | 前90天具体交付、预算/人员支持 | 面试沟通 | |
| 工作地点 | 常驻地、出差比例、远程政策 | Offer与劳动合同 | |
| 确定现金 | 月薪、月数、固定补贴、支付日期 | 书面文件 | |
| 浮动收入 | 绩效/佣金/股权条件、离职处理 | 书面条款 | |
| 试用安排 | 合同期限、试用期、薪酬与考核 | 合同/劳动合同法 | |
| 业务稳定性 | 产品、客户、经营风险的公开信息 | 公开资料并注明时点 | |
| 背调/体检 | 是否是录用条件、谁接收个人信息 | 合法授权和流程说明 | |
| 竞业/保密 | 与当前协议是否潜在冲突 | 本人合同与必要专业咨询 | |
| 终止机制 | 何种情况会撤销意向或延期 | 书面条件 | |

**止损规则**：招聘主体无法解释、要求转账/贷款换Offer、索取他人私密资料或要求从现公司非法带走资料，暂停进一步提供信息。企业登记真实也不代表岗位必然真实。

[查企业登记](https://bt.gsxt.gov.cn/) · [劳动合同法](https://www.mohrss.gov.cn/xxgk2020/fdzdgknr/zcfg/fl/202011/t20201102_394622.html)
