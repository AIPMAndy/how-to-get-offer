# AI 求职提示词｜复制后填入已脱敏的真实信息

## 01｜分析 JD，不要猜测公司

```text
你是严格的社招岗位分析员。根据下面这份JD：
1. 原文提取硬门槛、核心能力、加分项；
2. 提出7个面试官可能追问的问题，注明每个问题映射的JD原文；
3. 列出你仍不知道的岗位信息，必须写「未知」；
4. 不猜测企业内部预算、薪资或真实业务。
JD：〔只粘贴公开内容〕
```

## 02｜帮我审查简历真实性

```text
请对我的脱敏简历和公开JD做对抗式审查。
只允许使用我给出的事实，不能补造数据、学历、公司或经历。
请给出：对不上JD的要求、每条项目需要补的证明、会被追问穿的说法、删改建议。
先指出最可能被拒绝的5个原因；缺资料就提问，不编造。
JD：〔公开文本〕
简历素材：〔脱敏项目事实〕
```

## 03｜模拟面试官深挖

```text
请模拟一名严格、但不刻意刁难的〔岗位〕面试官。
基于下面我真实做过的项目，连续问我10个问题，一次只问一个。
每次回答后指出：事实不清、归因不清、决策依据不足，以及表达冗余。
不允许替我编造经历或给虚假百分比分数。结束后做可执行复盘。
项目：〔脱敏事实〕
JD：〔公开文本〕
```

## 04｜Offer 决策助手

```text
请把两个Offer的「确定固定现金」「可能得到的浮动收入」「股权及限制」「生活成本」「职业发展」「法律/经营风险」分开列出。
所有未知项写未知，不能把目标奖金当保底、不能拿股票估值当现金。
给出我还必须问HR的10个问题，最终建议按事实、假设、主观偏好分层。
Offer A：〔只输入可分享信息〕
Offer B：〔只输入可分享信息〕
```

**安全规则：** 不输入身份证、银行卡、工资流水、未公开客户数据、源代码、个人敏感信息或第三人隐私。AI 输出的政策/招聘/薪资判断必须人工到原始来源核验。
