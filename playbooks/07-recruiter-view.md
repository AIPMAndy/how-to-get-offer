# 对抗式 SOP 07｜把自己当成招聘经理来筛一次

招聘经理通常需要回答：候选人是否有必要能力证据、能否完成岗位前90天目标、是否会增加不确定成本。不同团队标准不同，不能推断所有HR都按一套“算法”选择。

## 从JD提炼评分证据

| 评价项 | 问自己的反例问题 | 应给的证据 |
|---|---|---|
| 岗位匹配 | 如果只看一页，我为什么相信你做过？ | 最近一个最相关项目、具体职责、成果口径 |
| 工作深度 | 你真正做的和团队做的如何区分？ | 具体设计、决策记录、失败处理 |
| 沟通协作 | 有冲突时能否基于事实推进？ | 与其他部门达成方案的真实案例 |
| 可信程度 | 某数字被反复追问还能一致吗？ | 定义、时间窗、证据边界 |
| 资源意识 | 面对人手和预算不足怎么排序？ | 权衡与舍弃的具体案例 |
| 风险 | 有没有容易引发背调不一致的地方？ | 真实任职时间、岗位名称、离职原因 |

## 模拟三轮

1. **20秒筛简历**：用A4打印，旁边放JD；画出匹配的三项可核验证据。找不到则回去重写第一屏。
2. **10分钟追问**：选择一条最亮眼的成果，连续问「为什么」「由谁决定」「怎么测量」「如果失败呢」。每一处不能回答标明真实缺口。
3. **反方质疑**：假设你是用人部门经理，写出不录取你的三个最合理理由。每个理由对应：补证据、补技能、或不申请该岗位。

**输出**：`反例 | 目前证据 | 缺口性质（表达/能力/岗位） | 下一动作 | 截止日期` 五列表。不允许将面试官偏好或企业预算等外部不确定因素伪装为自身缺陷。
