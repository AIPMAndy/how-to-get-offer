# SOP 03｜谈薪是一场“明确条件”的对话

## 谈之前做一页表

| 项目 | 当前确定 | 新机会确定 | 备注 |
|---|---:|---:|---|
| 税前固定月薪 |  |  | 不把提成算进去 |
| 固定支付月数 |  |  | 以书面条款为准 |
| 固定补贴 |  |  | 是否满足条件 |
| 目标年终/绩效 |  |  | 单列，可能不兑现 |
| 股票/期权 |  |  | 授予、归属和变现另算 |
| 通勤/房租/搬迁 |  |  | 用相同周期比较 |
| 额外工作时间 |  |  | 影响个人选择，不强行折成钱 |

## 完整对话演练

**HR：** 你现在期望多少？

**你：** 我想先确认一下岗位的职级、主要职责和薪酬构成。按目前沟通到的职责，我会重点承担【职责】，我希望固定月薪在【有依据的区间】。绩效和奖金的兑现规则也希望了解。

**HR：** 我们预算低一些。

**你：** 明白。请问固定部分目前可以明确到多少，奖金的考核与历史兑现情况怎样？如果固定薪资空间有限，是否存在其他已明确的补偿机制？我会综合考虑职责和职业路径。

**HR：** 你要今天就答应吗？

**你：** 谢谢你推进流程。这个决定涉及现岗位交接和家庭安排，我想把关键条款核实后在【双方能接受的日期】给正式答复。可以把具体方案以官方书面形式发我吗？

## 常见失误

- 把「预计有几个月年终」计入最低生活现金流。
- 仅凭HR口头赞许辞掉现工作。
- 忽略竞业、入职时间与背调条件。
- 拿不真实的竞争Offer施压；一旦核实会破坏信任。

**完成标准：** 理解固定与浮动条款、提出有依据的目标、形成待确认问题表。谈成与否取决于真实条件，不存在包赢话术。
