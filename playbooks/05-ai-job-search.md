# SOP 05｜AI 能帮你做什么，不能替你做什么

## 五个可用环节

| 工作 | AI 可以完成 | 必须人工核实 |
|---|---|---|
| JD 解析 | 提取硬条件、关键词、职责分组 | 真实招聘状态和业务实情 |
| 项目表达 | 用你输入的真实事实改写表达 | 绝不能自动补业绩数字 |
| 模拟面试 | 基于JD生成追问、给结构反馈 | 实际问法和招聘方标准 |
| 公司研究 | 根据你提供的材料整理假设 | 企业主体、经营情况、消息来源 |
| Offer 比较 | 把明确数字和不确定项结构化 | 税务、法务、期权兑现等 |

## 复制就能用的提示词

详见 [AI 提示词库](../templates/ai-prompts.md)。使用方法是：先输入脱敏事实，再让模型指出**证据不足**，最后由本人确认每个数字与主张。

## 四条安全底线

1. 不上传未授权的劳动合同、内部财务、客户名单、源码、绩效资料。
2. 不上传身份证号码、完整电话、住址、账户、体检等敏感个人资料。
3. 不允许 AI 编造学历、工作年限、雇主、项目数据、Offer。
4. 不用自动化脚本越过平台风控、批量骚扰HR或未经许可爬取招聘信息。

## 推荐的协作方式

人工定义目标 → AI拆JD与提问 → 本人补事实证据 → AI给出反面审查 → 本人定稿与投递 → 记录真实结果。

**验收：** 每段最终简历都能口头解释并拿出允许公开的证据；AI只是辅助编辑，不保证录用。
