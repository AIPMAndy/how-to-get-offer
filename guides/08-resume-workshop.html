实操课 08｜简历逐句改写：从经历描述到可信证据

目标：让看简历的人在前十几秒读懂你匹配哪种岗位、做过什么、贡献是什么。不要编造公司、职级、任职日期、团队人数或产出。

先建立「事实账本」

每个项目填八格：问题背景｜你的任务｜你亲手做的事｜为什么这么做｜替代方案｜结果和指标口径｜其他人的贡献｜可公开证据。公开证据可以是已公开产品链接、本人非涉密设计过程总结，不是前公司的源码、客户名单、内部数据、录屏或商业秘密。

三组改写示范（数据为虚构教学占位，不可照搬）

原句（不推荐）改写结构（示例，不得直接套数字）为什么改
负责用户增长，提升活跃在【项目】负责【渠道/产品机制】；对比【同口径前后时间窗】的【活跃口径】；结果从【基线】变为【结果】，同时监测【副作用指标】说明动作、口径和结果，不偷换因果
参与 AI Agent 研发针对【问题】设计【工具调用/人工审核/回退】流程，交付【可验证版本】；在【测试集】观察到【指标】；明确本人负责【模块】区分参与和独立负责
带领团队达成业务目标管理【实际人数/虚线协作人数】，为【目标】决定【取舍与资源配置】，结果【定量或可核实定性】；离职前团队状态【】管理岗要有决策而不只写团队规模

不得把相关性写成因果。例如「上线后订单增长」并不自动证明「因我上线导致增长」。写清期间、对照、其他影响因素；没有实验就使用「同期观察到」。

两种简历版本的具体顺序

通用结构：姓名/工作联系方式（最小化）→ 目标岗位与经验年限 → 3条最高相关证据 → 工作经历倒序 → 重点项目 → 必需技能/资质 → 教育背景。可根据行业调整，避免把版面审美当作统一录用标准。

A版本（目标现职相邻岗位）：第一页突出直接经验、项目结果、端到端责任。

B版本（跨行业转型）：先突出目标岗位能迁移的能力和公开作品，再用清楚的一句话解释行业差异。不要删掉无法解释的真实工作时间。

最后十项人工核验

  • [ ] 时间线与实际任职、社保/合同、背调材料一致
  • [ ] 项目结果的数据定义和统计期间可解释
  • [ ] 每项成果说明本人贡献，团队成果不全算自己
  • [ ] 第一屏出现目标JD的两到三项核心要求
  • [ ] 必需技能确实掌握，工具名不是装饰
  • [ ] 没有敏感身份信息（身份证、家庭住址、银行卡等）
  • [ ] 没有抄袭职位描述或用虚假关键词刷简历
  • [ ] 导出PDF后手机和电脑打开没有错字、截断、乱码
  • [ ] 文件名清楚，例如 产品经理_5年经验_版本A.pdf（公开分享可用匿名名）
  • [ ] 发给他人前核实接收人和公司，避免发错、过度扩散

完成标准：一份真实可解释的事实素材库，A/B两份不矛盾的简历，每份有目标JD的证据对应关系。卡住：没有漂亮数据时写清实际交付和约束，严禁编造。
