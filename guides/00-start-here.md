# 00｜3 分钟找到你的下一步

只回答三个问题：你现在有方向吗？有没有约面？有没有 Offer？按最早一个阻塞点进入对应环节。

| 目前状态 | 先打开 | 今天必须完成 |
|---|---|---|
| 完全不知道投什么 | [定位](01-positioning.md) | 3个可行方向+10份真实JD |
| 方向有了，投递没人理 | [简历](02-resume.md) | 1份目标JD对应简历，找人做30秒筛选 |
| 简历有了，找不到机会 | [渠道](03-channels.md) | 15家公司+5个有来源岗位 |
| 总卡在面试 | [面试](04-interview.md) | 1个按 STAR-L 拆透的项目 |
| HR 提到 Offer | [Offer](05-offer.md) | 问清固定薪资、浮动、主体和入职条件 |
| 已确定入职 | [入职](06-onboarding.md) | 确认书面入职条件和交接计划 |

**失业且现金吃紧：** 优先同步阅读 [失业自救指南](https://github.com/AIPMAndy/how-to-survive-unemployment)，评估现金流与劳动权益；不要因为急于上班就忽略招聘骗局。

**当下任务：** 写下「我最想去___岗位，目前最卡___，今天能交付___」。做完再打开 [在线行动看板](../index.html) 找到对应阶段。
